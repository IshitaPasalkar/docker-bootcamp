# Docker Compose Practice

## Project Overview

A simple Express.js application connected to MongoDB using Docker Compose.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Docker
- Docker Compose

## Project Structure

- Dockerfile
- docker-compose.yml
- Express Backend
- MongoDB Container

## Docker Commands

### Build and Start

```bash
docker compose up --build
```

### Run in Detached Mode

```bash
docker compose up -d
```

### Stop Containers

```bash
docker compose down
```

## What I Learned

- Building Docker images

- Docker Compose
- Running multiple containers
- Container networking
